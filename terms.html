Condiciones del Servicio

Última actualización: 16 de septiembre de 2026

Estas Condiciones del Servicio regulan el uso de Soniva, una aplicación y bot de Discord diseñado principalmente para ofrecer funciones de música.

Al utilizar Soniva, aceptas estas condiciones. Si no estás de acuerdo con ellas, debes dejar de utilizar el servicio.

1. Uso de Soniva

Soniva proporciona funciones relacionadas con música, incluyendo reproducción, administración de colas, volumen, repetición, letras de canciones y controles de reproducción.

Las funciones disponibles pueden cambiar conforme Soniva continúe desarrollándose.

2. Uso permitido

Al utilizar Soniva, aceptas no:

  • Utilizar Soniva para actividades ilegales.
  • Intentar obtener acceso no autorizado a los sistemas del servicio.
  • Explotar errores o vulnerabilidades de manera maliciosa.
  • Interferir intencionalmente con el funcionamiento de Soniva.
  • Abusar de los comandos mediante sistemas automatizados.
  • Utilizar Soniva de una manera que viole las reglas de Discord.

3. Disponibilidad

Intentamos mantener Soniva disponible y funcionando correctamente, pero no garantizamos que el servicio esté disponible permanentemente o completamente libre de interrupciones.

Soniva puede quedar temporalmente fuera de servicio debido a mantenimiento, actualizaciones, problemas técnicos o servicios externos.

4. Soniva Premium

Soniva puede ofrecer funciones Premium o de pago. Las funciones, precios y condiciones correspondientes serán mostrados antes de realizar una compra cuando estas opciones estén disponibles.

5. Servicios de terceros

Soniva funciona dentro de Discord y puede utilizar servicios externos necesarios para proporcionar determinadas funciones. Estos servicios pueden estar sujetos a sus propias condiciones y políticas.

6. Suspensión del acceso

Podemos limitar el acceso a Soniva cuando exista abuso, actividad maliciosa, explotación del servicio o incumplimiento de estas condiciones.

7. Limitación de responsabilidad

Soniva se proporciona según disponibilidad. No garantizamos que todas las funciones permanezcan disponibles permanentemente o que el servicio esté completamente libre de errores.

8. Cambios a estas condiciones

Estas Condiciones del Servicio pueden actualizarse debido a nuevas funciones, cambios técnicos o modificaciones en el funcionamiento de Soniva.

La fecha indicada al comienzo de esta página mostrará cuándo se realizó la actualización más reciente.

9. Contacto

Si necesitas asistencia relacionada con Soniva o estas condiciones, puedes comunicarte con el equipo de soporte oficial de Soniva.
